# 标记所有箱子Mod

- 在《逃离鸭科夫》地图上标记所有箱子和散落物，搜刮更方便！  
- 新增J-lab箱标记图标，刷加速器和晶体零件不用满地图跑着找了  
- 打开过的箱子颜色会变成白色，搜没搜过更一目了然  
- 搜刮过的空箱子会移除标记，不走回头路
- 散落物也标记在地图上，方便收集门卡、钥匙、针剂等物品，你懂得

  ### 2026.4.23更新：
- 新增筛选散落物的下拉菜单，与[标记地面散落物](https://github.com/lwt578/MarkerPickup)Mod合并（无需再安装此Mod）

  ### 2026.3.1更新：
- UI新增下拉菜单，可以筛选显示的箱子类型

  ### 2026.1.19更新：
- UI新增“不显示箱子标记”选项

  ### 2026.1.7更新：
- 新增UI，可以选择显示所有箱子/显示高价值箱子（J-lab箱，武器箱，资料箱，等等）
- 资料箱后面显示蓝图的名字，不过是英文的
